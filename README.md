# CryptoPulse - 虚拟货币实时分析系统

一个基于纯前端技术的加密货币实时分析系统，集成技术指标分析、新闻情感分析、智能交易信号生成等功能。支持移动端自适应，数据来自 CoinGecko 免费 API，无需后端服务即可运行。

## ✨ 功能特性

### 核心功能
- **实时价格监控** - 支持多种主流加密货币实时价格追踪
- **K线图表** - 交互式K线图，支持多时间周期切换（1H/1D/1W/30D）
- **技术指标** - MA7/MA25均线、RSI、MACD、布林带等常用指标
- **支撑压力位** - 自动计算关键支撑位和压力位
- **高低点标记** - 自动识别并标记近期高低点

### 智能分析
- **综合信号系统** - 结合技术面和消息面生成买入/卖出/观望信号
- **新闻情感分析** - 自动获取加密货币新闻，进行情感倾向分析
- **操作建议** - 智能生成加仓/减仓/观望等操作建议
- **评分系统** - 技术面评分、消息面评分、综合评分（0-100分）

### 用户体验
- **自选币种** - 支持添加/删除自选币种，最多10个
- **一键切换** - 快速切换不同币种查看分析
- **移动端适配** - 完美适配手机、平板、桌面端
- **自动刷新** - 数据自动更新，无需手动刷新
- **本地存储** - 自选列表保存在本地，下次访问自动恢复

## 📊 技术指标说明

### RSI (相对强弱指数)
- **周期**: 14
- **超买**: >70（可能回调）
- **超卖**: <30（可能反弹）
- **中性**: 30-70

### MACD (指数平滑异同移动平均线)
- **快线**: 12日EMA
- **慢线**: 26日EMA
- **信号线**: 9日EMA
- **金叉**: MACD上穿信号线（看涨）
- **死叉**: MACD下穿信号线（看跌）

### 均线 (MA)
- **MA7**: 7日简单移动平均线（短期趋势）
- **MA25**: 25日简单移动平均线（中期趋势）
- **多头排列**: 价格 > MA7 > MA25（看涨）
- **空头排列**: 价格 < MA7 < MA25（看跌）

### 布林带
- **中轨**: 20日SMA
- **上轨**: 中轨 + 2倍标准差
- **下轨**: 中轨 - 2倍标准差
- **触及上轨**: 可能遇压回调
- **触及下轨**: 可能获得支撑反弹

## 🎯 信号解读

### 综合评分
| 分数 | 信号 | 建议仓位 |
|------|------|----------|
| 70-100 | 强烈买入 | 60-80% |
| 58-69 | 买入 | 30-50% |
| 43-57 | 观望 | 20-30% |
| 30-42 | 卖出 | 10-30% |
| 0-29 | 强烈卖出 | 0-20% |

### 支撑压力位
- **强压力位**: 第二压力位，到达可考虑大幅减仓
- **压力位**: 第一压力位，到达可部分止盈
- **支撑位**: 第一支撑位，到达可轻仓试探
- **强支撑位**: 第二支撑位，到达可考虑加仓
